## 🎯 About the Module / អំពីម៉ូឌុល

**`universe_huokaingthara_ghost_stories_khmer_contact`** is the official story submission and editorial contact module for **និទានរឿងខ្មោចខ្មែរ (Ghost Stories Khmer)** under **UNIVERSE HUOKAING THARA Group**. It allows listeners, contributors, and partners to submit real-life eerie encounters, traditional Khmer legends, sponsorship inquiries, or feedback with anonymous identity options.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **📝 Story Submission & Inquiry Form:** Capture sender details, submission category, location/province, story title or subject, and full story details with real-time validation.
* **🧾 Automated Submission Receipt Modal:** Generates a unique tracking code (`UHT-GS-XXXXXX`) and submission summary upon successful form validation.
* **🛡️ Anonymity & Privacy Guidance:** Clear notice letting contributors request anonymity if they do not wish their real identity disclosed during narration.
* **🌐 Dual Language Switcher (Khmer / English):** Instant toggle supporting Khmer-only, English-only, or bilingual display modes.
* **🌙 Dark / Light Cyberpunk Theme:** Styled with the signature **UNIVERSE HUOKAING THARA** holographic scanline aesthetic and adaptive theme switching.

## 🛠️ Tech Stack & Architecture / បច្ចេកវិទ្យាប្រើប្រាស់
